# Этап 1. Анализ проекта: «Тренажер для обучения работе с инфекционными больными»

## 1.1. Предметная область
Что и для кого делаем:
Разрабатывается цифровой веб-тренажер для медицинского образования в сфере инфекционных болезней и эпидемиологии.
**Целевая аудитория:** 
Студенты медицинских вузов и колледжей

## 1.2. Проблема, которую решает проект
Проблема: 
Традиционное обучение работе с инфекционными больными сопряжено с высокими рисками. Студенты не могут полноценно практиковаться на реальных пациентах из-за риска инфицирования, а физические симуляторы дороги и малодоступны. Ошибки в реальной работе (например, при снятии СИЗ) приводят к заражению медперсонала.
Предлагаемое решение:
Виртуальная симуляция клинических сценариев с обратной связью. Это позволяет безопасно отрабатывать алгоритмы инфекционного контроля, учиться надевать/снимать СИЗ и тренировать общение с пациентом без риска заражения.

## 1.3. Функционал и архитектура

### Архитектура системы
Проект реализуется по клиент-серверной архитектуре (веб-приложение):
*   FE (Frontend — Интерфейс):** Каталог сценариев, карточка сценария (выбор уровня сложности), интерфейс чата, дашборд аналитики (графики, списки), интерфейс календаря.
*   BE (Backend — Серверная часть):** REST API (обработка запросов, выдача материалов, загрузка медиа), логика ветвления сценариев, обработка ответов ИИ-помощника, сбор статистики и формирование отчетов, API для работы с расписанием.
*   DB (PostgreSQL — База данных):** Хранение сценариев (`Scenario`, `ScenarioStep`, `AnswerOption`), контента (`ScenarioMaterial`), логов общения с ИИ (`ChatMessage`, `Feedback`), результатов попыток и ошибок (`Attempt`, `Statistics`, `ErrorLog`), а также событий календаря (`CalendarEvent`).

### Основной функционал
1.  Контент и сценарии: Выбор сценария из каталога, изучение текста клинической ситуации, просмотр изображений и видео-инструкций по СИЗ.
2.  Динамический чат / помощник: Ведение диалога с виртуальным пациентом, получение подсказок от ИИ-помощника, логика ветвления и формирование обратной связи по действиям пользователя.
3.  Аналитика и прогресс: Личный дашборд студента (графики ошибок, список пройденных сценариев), сбор общей статистики и агрегация результатов для отчетов.
4.  Календарь: Отображение расписания занятий, дат дедлайнов и напоминаний.
